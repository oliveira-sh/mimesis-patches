# Poltergeist changelog

## 1.0.0
- First version (each player's own, no host needed): random hauntings while you explore, whispers in your teammates' voices, eerie sounds, flickering lights, a figure staring at you from far away, something running past the edge of your view, and a jumpscare behind you when you turn around. Harmless (nothing touches health, radiation, items or the server), never while a monster is close, and never during a deathmatch (Deathmatch patch: fights between players stay fair). Intensity Calm / Spooky / Terror; each kind can be turned off. Debug mode: F8 in a level opens a window to start any haunting at once.
