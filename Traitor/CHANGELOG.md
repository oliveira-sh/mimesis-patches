# Traitor changelog

## 1.0.0
- First version (host and every player): the tram can offer a traitor destination (marked on its screen; Off / Rare / Often / Always). There everyone arrives alone somewhere inside the building (not in the tram), one player is secretly the traitor and monsters ignore them; the tram is locked for a while (No / 1:30 / 2:30 / 4:00) so the traitor can't strand everyone; catching the traitor pays the team a share of the stage's repair cost; the traitor wins if the rest die; the traitor is revealed at the end. Needs 3 players, all with the patch in a version that can play with the host's (each player's game tells the host, with the version of its messages; without it or with another one, no traitor destinations, and the host is told who; someone without it joining the tram later makes the lever go to a normal level).
